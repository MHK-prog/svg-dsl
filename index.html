Quick Syntax Guide

1. Absolute Point (X, Y) A = (40, 50)
2. Relative Point (dx, dy) from previous B = A(30, -20)
3. Polar Point (Radius @ Clockwise Angle) C = B @ (40, 90)
4. Line with Smooth Corners (Fillet) & Style A -- B -- C -- A : r10 stroke(#fff) fill(none) width(2)
5. Selective Fillet (Round specific corners) A -- B -- C : r8(B) stroke(#38bdf8)
6. Circle (Center Point, Radius) circle(A, 15) : stroke(#22c55e) fill(none)
7. Arc between two points (~Radius~) A ~30~ B : stroke(#f59e0b) Positive radius = outward arc | Negative (e.g. ~-30~) = reverse direction
